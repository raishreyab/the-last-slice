# 🎃 THE LAST SLICE – CURSE OF THE PUMPKIN 🐺

> *"One Pizzeria. One Curse. No Escape."*

A professional, 3D first-person horror survival game and gaming website built using **Three.js**, **JavaScript**, **Vite**, and the **Web Audio API**.

---

## 🌟 What's New: The Public Gaming Website & Cinematic Intro

### 1. 🎬 Cinematic Horror Introduction (6-Scene Prologue)
Before entering the pizzeria, players experience an animated opening sequence:
- **Scene 1 – The Beginning:** "Halloween, 1987..." Abandoned pizzeria exterior during a midnight storm with rain particles and lightning flashes.
- **Scene 2 – The Curse:** Mysterious glowing Jack-o'-Lantern with supernatural fire, revealing the failed ritual.
- **Scene 3 – The Disappearance:** Dark restaurant corridors with flickering emergency lights and locked doors.
- **Scene 4 – The Werewolf:** Frightening silhouette of Elias the Werewolf with glowing orange eyes in the fog.
- **Scene 5 – The Connection:** Antique sepia photograph showing your character's connection to the curse.
- **Scene 6 – Enter the Nightmare:** Dramatic title reveal with burning embers and action buttons: **⚡ ENTER THE NIGHTMARE** and **🌐 EXPLORE WEBSITE**.
- *Includes: Skip Intro button, scene jump dots, and replay options.*

### 2. 🌐 Professional Horror Gaming Website
- **Hero Showcase:** Atmospheric typography, tagline, game specifications, and one-click play triggers.
- **The Story Archives:** Complete lore on Elias, the failed resurrection ritual, and the 5 scattered pumpkin fragments.
- **Gameplay Features:** Deep dive into "The Beast Remembers" adaptive AI, 4 Jack-o'-Lantern abilities, 9-room map, tactile puzzles, and procedural audio.
- **Screenshots & Gallery:** 6 interactive chamber showcases with an interactive modal Lightbox.
- **Survival Guide & Controls:** Interactive tabbed interface for Desktop controls, Mobile touch virtual joystick, and noise intensity rules.
- **Team Credits:** Dedicated, editable team credits for VELMORA Studios and The Last Slice Team.

## 🕹️ First-Person Game Controls

### Desktop:
- **W / A / S / D:** Movement Acceleration
- **Mouse:** Look around (Pointer Lock)
- **E:** Interact / Pick Up items / Open & close doors
- **Ctrl / C:** Crouch (Stealth sneak: Noise 5)
- **Shift:** Run (Stamina drain: Noise 45)
- **F / Space:** Activate Jack-o'-Lantern ability
- **1, 2, 3, 4:** Switch between Soul Light, Ghost Vision, Flash Burst, and Soul Tracker
- **Tab / I:** Inventory grid & object lore inspection
- **Escape:** Pause menu

### Mobile Touch:
- **Left Virtual Joystick:** Analog movement
- **Right Screen Swipe:** Look around
- **[USE] Button:** Interact & pick up
- **[CROUCH] Button:** Stealth crouch toggle
- **[RUN] Button:** Sprint toggle
- **[PUMP] Button:** Trigger Jack-o'-Lantern ability
- **[BAG] Button:** Open inventory

## 🚀 Quick Start (Local Development)

```bash
# 1. Clone the repository
git clone https://github.com/your-username/the-last-slice.git
cd the-last-slice

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Open in browser:
# http://localhost:3000/
```

## 🛠️ Production Build & Public Deployment

```bash
# Build production bundle
npm run build

# Preview production build locally
npm run preview
```
